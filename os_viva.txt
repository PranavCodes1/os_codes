Q1. What is fork()?
→ fork() is a system call used to create a child process.

Q2. What does fork() return to the child?
→ 0.

Q3. What does fork() return to the parent?
→ The PID of the child.

Q4. What does getpid() do?
→ Returns the PID of the current process.

Q5. How many processes exist after successful fork()?
→ Two: one parent and one child.

Q6: What is a signal?
→ A signal is a software notification sent to a process to inform it that an event has occurred.

Q7: What is SIGINT?
→ SIGINT is an interrupt signal, commonly generated by Ctrl+C.

Q8: What does kill() do?
→ It sends a signal to a specified process.

Q9: What does getppid() return?
→ The parent process ID of the current process.

Q10: What does pause() do?
→ It suspends the process until a signal is received.

Q11: What is handler()?
→ It is a function that handles the received signal.

Q12: Why is wait(NULL) used?
→ To make the parent wait for the child process to terminate.
